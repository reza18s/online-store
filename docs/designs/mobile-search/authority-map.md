# Mobile search design authority

| Decision area                                       | Authority                                                                                                | How it is used                                                                                                                                                                 |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Color, type, shape, focus, and touch targets        | [`atelier-editorial.md`](../atelier-editorial.md), Section 18                                            | The Soft Modern refresh owns the current Atelier visual language and requires at least 44 × 44 px pointer targets.                                                             |
| Current rendered palette and responsive overrides   | [`storefront-reference.css`](../../../apps/web/src/styles/storefront-reference.css)                      | Runtime CSS confirms the Soft Modern page, surface, ink, muted, rosewood, and border values. New rules are scoped to `.listing-page--search` and the 767 px mobile breakpoint. |
| Query, filter, sort, results, and state transitions | [`listing-discovery.tsx`](../../../apps/web/src/features/catalog/components/listing-discovery.tsx)       | This component owns the `/products?q=…` results page and applies current URL state.                                                                                            |
| Query URL construction                              | [`build-discovery-href.tsx`](../../../apps/web/src/features/catalog/components/build-discovery-href.tsx) | The existing helper preserves compatible query parameters and removes `page` when `q` changes.                                                                                 |
| Product result actions                              | [`product-card.tsx`](../../../apps/web/src/features/catalog/components/product-card.tsx)                 | Shared product-card behavior remains the owner; search-only CSS enlarges its mobile targets.                                                                                   |
| Local preview imagery and labels                    | [`dev-store-fixtures-shared.ts`](../../../apps/web/src/shared/fixtures/dev-store-fixtures-shared.ts)     | Development fixtures provide deterministic local content for reference rendering. Asset licensing remains unknown.                                                             |

The route and commerce behavior remain owned by the application source. This board defines a responsive presentation contract for that existing flow; it does not create another catalog or product-card implementation.
