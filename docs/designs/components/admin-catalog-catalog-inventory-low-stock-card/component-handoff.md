## شواهد منبع

متن‌های ثبت‌شده: INVENTORY WATCH، موجودی کم، در حال دریافت هشدارهای موجودی...، دریافت دوباره، هشدار موجودی فعالی ثبت نشده است.، تنوع اصلی، ·، قابل فروش، مشاهده همه.

رویدادهای JSX ثبت‌شده: Button / onClick / برچسب ساختاری: دریافت دوباره. بعضی labelها توصیف ساختاری فرم/ناحیه‌اند و لزوماً متن دکمه نیستند؛ برد فقط از متن‌های کنش کوتاه و صریح CTA استفاده می‌کند.

متغیرهای state منبع: متغیری در inventory ثبت نشده است.

نشانگرهای state: نشانگر متنی ثبت نشده است.
