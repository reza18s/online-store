# SessionState — design handoff

- **شناسه:** `web-account-session-state`
- **محدوده:** `web`
- **منبع:** [`apps/web/src/features/account/components/session-state.tsx:21-95`](../../../apps/web/src/features/account/components/session-state.tsx)
- **وضعیت:** برد تصویری و رفرنس desktop/mobile ساخته شده؛ تمام چیدمان‌ها پیشنهاد طراحی‌اند.
- **فونت تصاویر:** Estedad SemiBold برای display و Vazirmatn برای متن فارسی؛ هر دو همراه مجوز SIL OFL 1.1 در render-source مرکزی موجودند.

## شواهد منبع

متن‌های ثبت‌شده: حساب کاربری، اطلاعات خصوصی شما فقط پس از ورود به حساب نمایش داده می‌شود.، در حال بارگذاری حساب کاربری، نشست شما منقضی شده است، دسترسی به حساب ممکن نیست، اتصال اینترنت برقرار نیست، حساب کاربری بارگذاری نشد، برای حفاظت از اطلاعات سفارش‌ها و آدرس‌ها دوباره وارد حساب شوید.، این حساب در حال حاضر اجازه استفاده از این بخش را ندارد.، اتصال را بررسی کنید و برای دریافت دوباره اطلاعات تلاش کنید.، دریافت اطلاعات حساب ممکن نشد؛ دوباره تلاش کنید.، ورود دوباره.

رویدادهای JSX ثبت‌شده: EmptyState / onAction. بعضی labelها توصیف ساختاری فرم/ناحیه‌اند و لزوماً متن دکمه نیستند؛ برد فقط از متن‌های کنش کوتاه و صریح CTA استفاده می‌کند.

متغیرهای state منبع: متغیری در inventory ثبت نشده است.

نشانگرهای state: نشانگر متنی ثبت نشده است.
