# فهرست تک‌به‌تک بردهای طراحی کامپوننت‌های NOVA

**به‌روزرسانی:** 2026-10-27

**مبنای سورس:** شاخه‌ی پیش‌فرض `main` در commit [`6e4770d`](https://github.com/reza18s/online-store/commit/6e4770d05ca67b2fecd337298359de8c6d838176).

**محدوده:** فقط طراحی و مستندات طراحی؛ کد محصول و رفتار برنامه تغییر نکرده است.

## وضعیت پوشش

- همه‌ی **۱۹۵ هدف تصویری مستقل** به‌صورت تک‌به‌تک برد دارند: **۱۲ برد دقیق موجود + ۱۸۳ برد تازه**؛ تعداد برد مستقل باقی‌مانده **۰** است.
- از ۲۰۳ نماد JSX، **۸ wrapper/router/provider** سطح تصویری مستقلی ندارند؛ علت و صفحه‌های پوشش‌دهنده در جدول پایین ثبت شده‌اند.
- سه بسته‌ی تکمیلی `catalog-filter-sidebar-gsap`، `category-sort-select` و `admin-order-action-panel` در عدد ۱۹۵ شمرده نشده‌اند.
- مجموعه‌ی [بردهای صفحه](../pages/README.md) همچنان ۳۶ گروه صفحه و ۱۰۷ قاب مسیر/حالت دارد.
- QA برای ۱۸۳ بسته‌ی تازه: schema و بررسی‌های معنایی، hash منبع، لینک/خروجی، فونت، ابعاد PNG و scene graph همگی **PASS** هستند؛ سطح کلی `PASS_WITH_WARNINGS` است چون اجرای تعاملی اپ انجام نشده است. برای ۱۲ بسته‌ی قبلی، گزارش QA اصلی کنار همان پکیج مانده و وضعیت هر گزارش در جدول آمده است.

## فونت تصاویر

- تیترهای فارسی با **Estedad SemiBold 8.5** و متن/کنترل‌ها با **Vazirmatn Regular/SemiBold v33.003** رندر می‌شوند.
- Estedad برای بردهای storefront جایگزین پیشنهادیِ تصویری برای نقش display است؛ این انتخاب، فونت اپ را تغییر نمی‌دهد. حروف فارسی و RTL با Pillow RAQM شکل‌دهی می‌شوند.
- فایل‌های فونت، متن مجوز و hashها در [اعتبار و منبع فونت‌ها](render-source/FONT-CREDITS.md) ثبت شده‌اند.
