## How this file stays current

- The integration owner updates this ledger after every merge, branch/PR creation, PR state change, agent dispatch, resume or stop, validation result, blocker, provider decision or visual-reference decision.
- Each update records a verification date, the relevant branch/commit/PR, and the evidence or limitation. Agent reports are inputs; completion is not accepted without checking the actual branch, diff, PR and validation state.
- Sub-agents do not edit this ledger. They return the structured task report from the optimized plan; the integration owner records the accepted result here.
- Do not mark a task complete because a branch exists. A task is complete only after its scoped diff, PR state, tests and known blockers have been reviewed.
- `docs/remaining-work-plan-optimized.md` remains the scope/dependency source of truth. `.agents/project-memo.md` points to this ledger for durable workspace context.
