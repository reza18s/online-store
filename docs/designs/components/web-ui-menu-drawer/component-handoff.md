# MenuDrawer — design handoff

- **شناسه:** `web-ui-menu-drawer`
- **محدوده:** `web`
- **منبع:** [`apps/web/src/shared/ui/menu-drawer.tsx:10-67`](../../../apps/web/src/shared/ui/menu-drawer.tsx)
- **وضعیت:** برد تصویری و رفرنس desktop/mobile ساخته شده؛ تمام چیدمان‌ها پیشنهاد طراحی‌اند.
- **فونت تصاویر:** Estedad SemiBold برای display و Vazirmatn برای متن فارسی؛ هر دو همراه مجوز SIL OFL 1.1 در render-source مرکزی موجودند.

## شواهد منبع

متن‌های ثبت‌شده: منوی فروشگاه، بستن منو، ورود به حساب کاربری، پشتیبانی و تماس.

رویدادهای JSX ثبت‌شده: div / onMouseDown / برچسب ساختاری: منوی فروشگاه / بستن منو / ورود به حساب کاربری؛ aside / onKeyDown / برچسب ساختاری: منوی فروشگاه / بستن منو / ورود به حساب کاربری؛ Button / onClick / برچسب ساختاری: بستن منو؛ a / onClick. بعضی labelها توصیف ساختاری فرم/ناحیه‌اند و لزوماً متن دکمه نیستند؛ برد فقط از متن‌های کنش کوتاه و صریح CTA استفاده می‌کند.

متغیرهای state منبع: متغیری در inventory ثبت نشده است.

نشانگرهای state: نشانگر متنی ثبت نشده است.
